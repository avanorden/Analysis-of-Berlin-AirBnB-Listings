# Analysis-of-Berlin-AirBnB-Listings

Repository compiling MySql scripts that provide information on making AirBnB reservations in Berlin.
The analysis is intended to help renters make more informed decisions on selecting a listings, such as estimations of price, busyness, and availability.

## Operations Preformed

  * Find the average prices for each neighborhood
  * Rank each neighborhood group by its average price
  * rank each month by how busy they were, and compare an individual neighborhood group's month rankings to the overall month ranking
  * Find if a selected AirBnB listing exists in the same location at a lower price
  * Given a neighborhood group, find if there is an open range of listings based on a specified start and end date
